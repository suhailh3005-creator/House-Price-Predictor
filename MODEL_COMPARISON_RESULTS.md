# Model Comparison Results

This experiment compares three regression models on the same dataset split and feature set to make the evaluation fair.

## Experimental Setup

- Dataset: `data/houses.csv`
- Target variable: `house_price`
- Preprocessing: same pipeline as the project, including the feature engineering in `src/features.py` and the base validation in `src/data.py`
- Feature set: `area_sqft`, `bedrooms`, `bathrooms`, `age_years`, `location_score`, `parking_spaces`, `area_per_bedroom`, `house_age_group_code`
- Train/test split: `train_test_split(..., test_size=0.2, random_state=42)`
- Random state: 42 for the split, Decision Tree, and Random Forest models
- Models compared:
  - Linear Regression
  - Decision Tree Regressor
  - Random Forest Regressor
- Model fitting time measurement: `time.perf_counter()` around `model.fit(X_train, y_train)` only
- Python version: 3.14.7
- scikit-learn version: 1.9.1

## Results & Benchmark Data

| Model | MAE ($) | RMSE ($) | $R^2$ Score | Training Time (ms) |
| :--- | :---: | :---: | :---: | :---: |
| **Linear Regression** | 17340 | 23260 | 0.973 | 1.56 |
| **Decision Tree** | 43219 | 54819 | 0.848 | 2.04 |
| **Random Forest** | 29295 | 39583 | 0.921 | 111.04 |

## Observations

- The best MAE was achieved by the **Linear Regression** model at $17,340.
- The best RMSE was also achieved by the **Linear Regression** model at $23,260.
- The highest $R^2$ score was achieved by the **Linear Regression** model at 0.973.
- The fastest model to train was **Linear Regression** at 1.56 ms, followed closely by the **Decision Tree** at 2.04 ms.
- The **Decision Tree** performed worse than both of the other models on the same test set, with MAE of $43,219, RMSE of $54,819, and $R^2$ of 0.848. This suggests it generalized less well in this setup than the linear baseline and the random forest.
- The **Random Forest** improved substantially over the single Decision Tree, reducing MAE from $43,219 to $29,295 and increasing $R^2$ from 0.848 to 0.921. This indicates the ensemble was more robust on the test set.
- The trade-off between predictive performance and training time is visible here: the Random Forest was much slower to train (111.04 ms) but still delivered better performance than the single Decision Tree. The Linear Regression baseline remained both the fastest and most accurate in this dataset.
- The Linear Regression baseline compares very well with the non-linear models here. It is simpler, quicker, and had the strongest test-set metrics.
- The most notable result is that the non-linear models did not outperform the linear baseline on this synthetic educational dataset, despite their capability to capture more complex patterns.

## Reproducibility Notes

This comparison was generated by running the project’s standard training pipeline from `src/train.py` in the existing environment. The same train/test split, same feature engineering, and same target variable were used for all three models.
